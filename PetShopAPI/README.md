## Задачи проекта:
* дополнить диаграмму контейнеров модели С4, по результатам интервью с заказчиком
* спроектировать API, реализующий новую функциональность
* описать API на YAML

## Используемый стек:
C4, Draw.io, Google docs, YAML, Swagger
