## Задачи проекта:
* определить требования к приложению для умного дома
* смоделировать предметную область
* создать интерактивный прототип пользовательского интерфейса приложения
* разработать ПМИ

## Используемый стек:
User Story Map, User Stories, Job Stories, DFD, ER-диаграмма, Miro, Figma, Draw.io, Google docs, Яндекс Документы
